## 这是什么

在开源项目 [RikkaHub](https://github.com/rikkahub/rikkahub) 基础上做的增强版：保留原有全部能力，重点打磨**长时间任务、多模型协作、多账号多密钥**这三类实际场景。

包名与官方版不同，**能和官方版同时安装**，数据互不影响。仓库里是**完整可编译源码**（不是补丁）。

> ⚠️ 个人维护，**与 RikkaHub 官方无关**；遇到问题请在本仓库反馈，别去找官方。

## 和官方版的主要区别

1. **回复被掐断会自动接着写（异常续跑）**：撞输出上限 / 断网 / 服务商报错 / 模型"没说完就停"都会续；两种方式可切换（发"继续" / 重新生成最后一段）；次数 0~99 可设；提示里带**真实错误原文**；程序级去重防复读。
2. **圆桌会议**：多个模型各出方案、互相反驳、主模型拍板；每个座位都是一条真实对话，能进去看思考与工具调用，可逐座位启停 / 换模型 / 重试 / 跳过 / 续跑。
3. **子代理（Codex 风格）**：主模型把活派给子代理，结果只回一份摘要，主对话上下文干净；角色可分派不同模型、备用模型自动接力；写权限白名单（无 shell、不能编译、不能删文件）。
4. **官方账号登录，不用填 Key**：Gemini / ChatGPT（Codex）/ Grok 三套通道，支持多账号轮询；凭据加密只存本机。
5. **每个对话记住自己的模型**：切回旧对话自动恢复上次用的模型（照 Chatbox 的做法），默认开；顺带修好了"跨文件夹切换会串模型""切回旧对话有时不恢复"两个毛病。
6. **本对话 token 明细 + 自动算花费**：顶栏常驻「↑输入 ↓输出 Σ合计」，回答过程中实时刷新、带缓存命中率；可给模型填单价（输入 / 输出 / 缓存命中，按每百万 token），自动估算**本对话花了多少**；没填价的模型红字标「未计入」，绝不用 ≈0 冒充免费。
7. **自动压缩**：上下文一到触发值就自动压缩对话，压缩前**先建一个新分支**（原对话一字不少地保留）；触发值可自定（默认 115K token），还能给指定模型单独设；输入框上方常显「上下文占用」条，和触发判定用同一套口径——数字到点就真的会压缩。
8. **手动压缩双模式**：对话菜单里手动压缩时可选：智能（照 Codex）/ 经典（官方旧版：自选目标 token 与保留条数），会记住你上次的选择。
9. **重点内容标色（红 / 黄 / 绿）**：默认关、**零注入**；打开时只在系统提示词末尾加一段中性说明，模型可用可不用。
10. **多密钥 / 多账号轮询**：某把 Key 报错自动换下一把、**整池轮完为止**；按报错文字识别余额 / 鉴权 / 限速；冷却期满自动回池；已经吐出内容就绝不换 key 重发（防前半段重复）。
11. **备份与恢复**：本地整包导入 / 导出（聊天记录 + 文件），**能直接导入官方版导出的备份**（旧版数据库结构自动适配）；修好"导入到一半被页面回收打断、还误报成恢复失败"（官方版同款毛病）；导出中断不再留下半个坏包；也支持从 ChatBox / Cherry Studio 导入。
12. **从官方版迁入工作区**：整树搬过来、断点续传、带进度通知，只读不写入。
13. **输入面板与文件**："+" 面板保留拍照 / 照片 / 视频 / 音频 / 文件 / 文档全部入口；附件条重做（失败可重试、连续添加、文档显示大小）；工作区图片直接显示在对话里、不产生副本；文件发到对话上限 256MB → **10GB**；存储管理支持批量删除；消息里的视频可内嵌播放。
14. **渠道兼容修复**：商汤（DeepSeek"思考吃满输出预算导致空回"的根因；kimi 不支持询问卡片已单独屏蔽）；询问卡片容错降级 + 新增「跳过」按钮（选项都不想要也能继续）；Exa 搜索改片段优先 + 分段读取；Gemini 429 按端点分区修复；Grok 空回复 / 额度判定 / 冷却修复；流式失败兜底等。
15. **其它**：应用名「豆沙包调用器」+ 自定义图标 + 默认头像；「强制翻阅技能」开关；删掉设置里的 QQ 群 / Discord / 赞助页（不影响功能）。

## 自己编译

需要 JDK 17 + Android SDK（compileSdk 37），仓库自带 Gradle wrapper：

```bash
./gradlew :app:assembleDebug      # 出能装的测试包
./gradlew :app:assembleRelease    # 出正式包（需自备签名）
```

- 签名从根目录 `local.properties` 读取；没有也能编译，但产出是未签名的包；
- `material3/material-color-utilities` 源码已直接包含，无需拉取子模块；
- 仓库内置占位用的 `app/google-services.json`（不连任何真实服务），开箱可编译；
- Web UI 静态资源是构建产物，需要时 `./gradlew :web:buildWebUi` 生成。
