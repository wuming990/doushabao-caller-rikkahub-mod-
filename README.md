# 豆沙包调用器

**基于 RikkaHub 二次开发的安卓 AI 聊天客户端**

上游基线：RikkaHub **3.1.1** ｜ 本版：**3.1.1-mod15**（versionCode 1017）｜ 包名：`me.rerere.rikkahub.mod`

## 这是什么

在开源项目 [RikkaHub](https://github.com/rikkahub/rikkahub) 基础上做的增强版：保留原有全部能力，重点打磨**长时间任务、多模型协作、多账号多密钥**这三类实际场景。

包名与官方版不同，**能和官方版同时安装**，数据互不影响。仓库里是**完整可编译源码**（不是补丁）。

> ⚠️ 个人维护，**与 RikkaHub 官方无关**；遇到问题请在本仓库反馈，别去找官方。
> 官方原版介绍页（`README_ZH_CN.md` / `README_ZH_TW.md`）里的 QQ 群、Discord、赞助商、捐赠内容已删除，只保留功能介绍。

## 新增功能（官方版没有）

| 功能 | 一句话说明 |
|---|---|
| **自动续跑** | 回复写到一半被掐断（撞上限 / 断网 / 报错 / 没说完就停）会自动接着写完；两种方式可切换（发"继续" / 重新生成最后一段）；次数 0~99 可设；带真实错误原文；程序级去重防复读 |
| **圆桌会议** | 多模型各出方案、互相反驳、主模型拍板；每个座位可进去看思考与工具调用 |
| **AI 讨论群组** | 多个模型在同一个对话里**实时轮流讨论**（不是各写一份再汇总）：成员互相接话、条件不足时向你提问、你补充后从断点接着讨论、你可以随时插话；支持「我的方案」一键套用、暂停与彻底删除分开、面板整块折叠；**停下等你的阶段会发系统通知**；面板上可直接点名「你来说」（没开口的那位可当场换人）；群设置里可原地更换某位成员的模型；**「只保留发言正文」开关**（打开后群里聊出的思考过程、工具调用与搜索结果不再进上文，开群之前的原对话照旧整份带）；讨论上文长度上限可自填（0 = 不限） |
| **子代理** | 主模型派活给子代理、只回一份摘要；角色可分派模型；写权限白名单（无 shell / 编译 / 删除）；可授权检索历史对话；**可把主对话完整原文交给子代理**（可选，带字数上限，超长时保留开头结尾并写明省了多少）；续跑次数可调，且**手动「继续输出」与自动续跑共用同一个上限**、回执里显示的是真实可续次数 |
| **官方账号登录** | Gemini / ChatGPT / Grok 直接登录官方账号，不用填 Key；多账号轮询；凭据加密只存本机；Gemini 的**自带谷歌搜索可与工作区工具同轮使用** |
| **Gemini 网页版通道** | 用 Google 账号的网页登录态直连（与反重力通道互不影响）：**应用内一键登录**自动取回登录态并记住登录时的浏览器标识，也保留「从剪贴板填入」兜底；换账号与续期分开处理，登录态过期会明确提示 |
| **对话记住模型** | 每个对话记住自己最后用的模型，切回来自动恢复（照 Chatbox），默认开；创建分支时一并带过去 |
| **本对话 token 明细 + 算花费** | 顶栏常驻消耗、过程中实时刷新、带**缓存命中率百分比**；填单价（输入 / 输出 / 缓存命中，**支持按次计价**）自动估算本对话花费；生成中就刷新，不等回复结束 |
| **自动压缩** | 到触发值自动压缩、先建分支保留原对话；触发值可自定、可按模型单独设；**可指定固定的压缩模型**（官方 3.1 砍掉了这一项，这里补回）；占用条常显 |
| **超长工具输出不丢内容** | 结构化输出（如搜索结果）不参与截断；预览改为**开头 + 结尾**，命令的报错和最终结论不再被切掉；**只有确认模型能把原文读回来才落盘并给路径**；留档按 7 天 / 512MB 清理，启动不再清空历史输出目录 |
| **空回复不再装死** | 模型一个字都没吐时按原因分档处理：不计费的自动重试，计费的给出人话解释并附上服务商给的结束原因，不再当成正常回复静默结束 |
| **重点标色（红/黄/绿）** | 默认关、零注入；打开只给模型一段中性说明，可用可不用 |
| **强制翻阅技能** | 默认关；打开后模型首次回答前必须先翻阅一遍已启用技能的说明（SKILL.md）再动手，不会漏用；没开技能时完全不注入 |
| **多密钥 / 多账号轮询** | 一把报错自动换下一把、整池轮完；按报错文字识别限额；吐过内容绝不重发 |
| **思考卡片可收起** | 单步也能收起、生成中显示最后几步、结束自动全收；等你确认/回答的步骤永不隐藏 |
| **拖拽排序** | 对话文件夹与技能列表长按拖动排序 |
| **从官方版迁入工作区** | 把官方版里的工作区文件整树搬过来，断点续传、只读不写入 |

## 跟官方 3.1.x 一起升级上来的能力（官方新增，非我们开发）

源码基线已从官方 2.5.6 跟到 **3.1.1**，官方这几轮新增的能力本仓库同样具备：

- **SSH 远程工作区**：新建工作区时可选「本地」或「SSH 远程」，工具直接在远端机器上跑；
- **内置终端**：工作区里开可交互的终端会话；
- **聊天悬浮窗**：在其他应用上层浮着聊天，设置里有开关与授权入口；
- **媒体生成**：图片与视频生成通道；
- **Skills 技能体系**：除 MCP 之外新增官方技能格式支持；
- **文件型记忆**：记忆从"类 ChatGPT 记忆"改为官方基于文件的实现；
- **扫码导入**：用相机扫二维码导入供应商配置；
- **界面换成官方 Material 3 Expressive 风格**，模型能力表改从 models.dev 读取并在后台刷新；
- 头像裁剪走官方新流程，HEIF/HEIC（含 HDR）照片也能正常裁剪。

## 自己编译

需要 JDK 17 + Android SDK（compileSdk 37、minSdk 26、targetSdk 37），仓库自带 Gradle wrapper（9.6.0 / AGP 9.4.0）：

```bash
./gradlew :app:assembleGithubDebug      # 出能装的测试包
./gradlew :app:assembleGithubRelease    # 出正式包（需自备签名）
```

官方 3.1 起分了 `github` / `play` 两个发布渠道，**本仓库交付的是 `github` 渠道**，所以任务名带 `Github`。

- 签名从根目录 `local.properties` 读取；没有也能编译，但产出是未签名的包；
- `material3/material-color-utilities` 源码已直接包含，无需拉取子模块；
- 仓库内置占位用的 `app/google-services.json`（不连任何真实服务），开箱可编译；
- Web UI 静态资源是构建产物，需要时 `./gradlew :web:buildWebUi` 生成；
- `app/src/main/jniLibs/` 下的原生库里，`libtermux.so` 取自上游官方发布产物（本仓库不重新编译它，来源与哈希记录在 `terminal/build.gradle.kts` 的注释里），其余为随源码一起提供的预编译库。
