**基于 RikkaHub 二次开发的安卓 AI 聊天客户端**

## 这是什么

「豆沙包调用器」是在开源项目 [RikkaHub](https://github.com/rikkahub/rikkahub) 基础上做的增强版：保留原有全部能力，并针对**长时间跑任务、多模型协作、多账号多密钥**这些实际使用场景做了大量改进。

包名与官方版不同，**可以和官方版同时安装**，两套数据互不影响；想把官方版里的工作区文件搬过来，用内置的「从官方版导入」即可（见下文第 4 节）。

本仓库提供的是**完整可编译源码**（不是补丁），方便查看改动、自行编译或二次开发。

> 版本号说明：二改版沿用 `2.4.x-modNN` 的命名一路递增，功能基线已经合并到官方 **2.5.0**，所以版本号看起来比上游小，实际是同一代基线。

> ⚠️ 本版由个人维护，**与 RikkaHub 官方无关**。使用中遇到的问题请在本仓库反馈，不要去找官方。

## 和官方版的主要区别

### 1. 回复被中断会自动接着写（异常续跑）

官方版对网络类错误有「自动重试」（把整趟请求重发一遍），但**不会把已经写了一半的回答接着写完**。本版会在这种情况下**断点续写**：

- **什么时候会续**：回复已经开始输出、中途被打断——撞输出上限、连接断开、服务商报错、模型"没说完就停"（正文和工具调用都没有新增）；
- **什么时候不续**：你主动点停止；内容审核 / 安全拒答类拦截（续了也会被再拦下）；一个字都还没输出就失败的中断（这种走的是"整趟重试"，不属于续写）；
- **两种续跑方式可切换**：① 发送"继续"（模型接着写）／② 重新生成最后一次输出（把最后一段整段重来）；
- 续跑次数上限 **0~99**（默认 3），用尽即停；
- 续跑提示里显示**真实错误原文**，能直接看到是哪一步出的问题；
- 对话底部可显示"本对话已续跑几次"（可关闭）；
- 程序级去重兜底：续跑时逐字重复的长段落会被剪掉，避免复读。

### 2. 圆桌会议（多模型讨论出方案）

让多个模型先各自出方案，再互相反驳，最后由一个主模型拍板。四个阶段：任务合同 → 并发探索与初案 → 针对性反驳 → 主模型拍板。每个座位都是一条真实对话，可以点进去看思考与工具调用；支持逐座位启停、换模型、重试、跳过、续跑。

### 3. 子代理（Codex 风格）

主模型可以把活派给独立的"子代理"去做，结果只回一份摘要，主对话上下文保持干净。支持：

- 探测位 / 编程位 / 审查位等角色，每个角色可单独指定模型，备用模型自动接力；
- 写权限白名单（子代理**没有 shell、不能编译、不能删文件**）；
- 卡住判定与工具超时设置、按助手开关子代理功能；
- 可选「允许子代理检索历史对话」（**默认关**；开启时子代理能看到的内容会发给模型，界面有明示）。

### 4. 从官方版迁入工作区

可以和官方版共存，也**能把官方版里的工作区文件整树搬过来**：

- 授权官方版的目录后自动列出工作区 → 选择要复制的 → 带进度复制；
- **断点续传**：中断后保留半成品，可继续；续传时跳过已复制且大小一致的文件；
- 长任务走前台服务 + 通知栏进度，降低被系统杀掉的概率；
- **只读官方版数据，绝不写入**，不会破坏官方版的任何文件。

### 5. 官方账号登录（不用填 API Key）

三套官方账号通道，直接在 App 里登录官方账号即可使用：

- **Gemini（谷歌账号）**：走 Cloud Code Assist 通道，支持额度查询与多账号轮询；
- **ChatGPT（Codex 账号）**；
- **Grok（xAI 账号）**：支持设备码登录、凭据批量导入、多账号轮询与撞额度冷却。

凭据用系统密钥库加密、只保存在本机；登录和刷新时按官方流程与对应服务商通信。

### 6. 手动压缩：双模式

对话菜单里手动压缩上下文时，可以自己选：

- **智能模式**（默认）：照 Codex 的压缩流程，摘要长度由模型自己决定；
- **经典模式**：官方原有的压缩流程（自选目标 token 数与保留消息条数），按需求加回。

会记住你上次的选择。

### 7. 自动压缩可按模型单独设阈值

除了助手级的自动压缩触发值，还能给**指定模型**单独设自动压缩触发值（只有列进去的模型走各自的值，其余仍用助手的值）。

配套：输入框上方常显「当前上下文占用」条（默认开、可关），显示口径与自动压缩的触发判定完全一致——数字走到上限就是真的会触发压缩。

### 8. 每个对话记住自己的模型

照 Chatbox 的做法：每个对话记住自己最后用的模型，切回来自动恢复；新对话沿用最近使用的模型。有开关（默认开）。不会再出现"新开对话切了模型，回到旧对话模型也跟着变了"。

### 9. 本对话 token 累计

对话页顶栏常驻一行"本对话 ↑输入 ↓输出 Σ合计"，点开看明细（输入 / 输出 / 其中思考 / 其中缓存 / 合计）。

修掉了一个老问题：同一条回答跨工具轮、跨续跑轮会重复发送上下文并重新计费，旧统计只留最后一轮、严重偏小；本版按**真实消耗**累计，并把思考 token 单独列出来。可关闭显示。

> 口径：**不含**起标题、压缩、翻译等后台调用，也**不含**子代理消耗（弹窗里有同样说明）。

### 10. 重点内容标色（红 / 黄 / 绿）

给模型一个可选的排版能力：输出时用红、黄、绿三种颜色把重点标出来。

- **关闭时（默认）零注入**，模型全程不知道这个功能存在；
- 打开时只在系统提示词**末尾**加一段中性说明（告知界面支持这三种颜色、可用可不用），不含任何"该怎么回答"的指令。

### 11. 输入面板与文件

- "+" 面板保留**拍照 / 照片 / 视频 / 音频 / 文件 / 文档**全部入口；
- **附件条重做**：处理中和失败的附件单独显示（失败可点重试）、尾部常驻"添加"按钮可连续添加、文档附件显示文件大小；还有附件没处理完时不允许发送；
- 文件选择器：打开直接落在"最近文件"，文件名最多两行、扩展名做成独立小标签；
- **独立文件管理页**，导出文件直接写入系统下载目录，不弹"另存为"；
- 对话消息里的视频可以**直接内嵌播放**（默认不自动播放，点播放键才开始）；
- 模型/工作区把文件发到对话里时，单次上限从 256MB 提到 **10GB**；
- 工作区里的图片可以直接在对话里显示（不产生额外副本）；
- 存储管理支持**批量删除**（生图多了不用一张张删）。

### 12. 多密钥 / 多账号轮询

- 一个供应商里填多个 API Key，会自动轮换：某把密钥报错就换下一把，**整池轮完为止**；
- 密钥类错误（余额不足 / 鉴权失败 / 无权限 / 限速）按 HTTP 状态码与常见报错文案**双重识别**后换 key；
- 额度与冷却判定**主要看报错文字**——同一件事不同服务商给的状态码不一样，只看状态码必然漏判；
- 被判定"暂时不可用"的密钥进入冷却，冷却期满自动回到池子；
- 已经吐出内容后绝不换密钥重发（防止前半段重复）。

### 13. 渠道兼容与稳定性修复

- **商汤（SenseNova）**：修复 DeepSeek 模型"思考吃满输出预算、导致正文为空"的问题；
- **询问用户卡片**：模型把选项写坏（缺字段、形状不对）时自动降级，显示输入框兜底，不再卡死；
- **Exa 搜索**：改为片段优先 + 定向查询 + 结构化分段读取，长网页可以按段读；
- **Gemini 429**：官方账号通道按分区走对应端点，额度改读官方配额接口；
- **Grok**：空回复零报错、额度判定、撞额度冷却等修复；
- 流式失败兜底：SSE 建流失败但没有任何异常对象时，不再被误判成"回答正常结束"；
- 从其他 App 分享文件进来时，正确解析系统给的附件地址。

### 14. 其他改进

- 应用名改为「豆沙包调用器」，配套**自定义应用图标**（含单色主题图标）与通知栏图标，内置默认用户头像（老安装无需迁移即可看到）；
- 「强制翻阅技能」开关（默认关）：开启时要求模型先翻阅已启用技能的说明再动手；
- 输入框与附件细节、全角分隔符解析等一批小修复；
- 删掉设置里的 QQ 群、Discord 入口与赞助 / 捐赠页面（不影响任何功能）。

## 自己编译

需要：JDK 17、Android SDK（compileSdk 37），仓库自带 Gradle wrapper。

```bash
./gradlew :app:assembleDebug      # 直接出一个能装的测试包
./gradlew :app:assembleRelease    # 出正式包（需自备签名，见下）
```

> 说明：
> - **签名**：Release 签名从项目根目录的 `local.properties` 读取（`storeFile` / `storePassword` / `keyAlias` / `keyPassword`）。没有这个文件也能编译，但产出的是**未签名**的包，需要自己配置签名后才能安装发布。
> - `material3/material-color-utilities` 在上游是一个 git 子模块，本仓库已把它的源码直接包含进来，无需额外拉取子模块即可编译；
> - 仓库内置了一份本地构建用的 `app/google-services.json`（全部为占位值，不连接任何真实服务），开箱即可编译；
> - Web UI 的静态资源是构建产物，仓库里没有提交，需要时执行 `./gradlew :web:buildWebUi` 生成。
